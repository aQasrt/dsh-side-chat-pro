# 侧边聊天 Pro（dsh-side-chat-pro）

在 DSH 里选中一段对话文字，然后三选一：**侧边栏提问**、**翻译**、**名词解释**。

基于 [dsh-side-chat-plus](https://github.com/heartmove/dsh-side-chat)（MIT，作者 heartmove / dsh-sub-chats contributors）修改，保留它的全部能力，并新增划词翻译与名词解释。

## 新增能力

- **划词三选一**：选中文字后浮出菜单，可选「侧边栏提问 / 翻译 / 名词解释」。
- **翻译结合上下文**：把选中文字所在的段落一起交给模型判断词义，输出 **1–5 个按贴合度排序的候选译法**，一个英文词在不同语境下的不同意思都能列出来。
- **名词解释**：用一到三句话说明这段内容里的名词或概念是什么、在这里起什么作用，同样带上上下文。
- **独立小浮层**：翻译和解释贴在选区旁弹出，可复制、可关闭，不往主会话里写任何消息。
- 翻译/解释复用侧聊当前的模型与思考难度；思考档位是 high/xhigh/max 时自动降到 low，让短任务更快返回。

## 继承自上游的能力

- **侧栏提问**：选中文字开一个独立的侧边子会话，继承主会话的模型、权限，不污染主对话。
- **悬浮球**：窗口右侧常驻按钮，可拖动并记忆位置，一键开关侧聊面板。
- **父会话上下文**：新侧聊会带上父会话最近 5 轮对话（上限 1 万字符）；需要更早内容时模型可调用 `sidechat_read_parent` 往前翻。
- **侧聊持久化**：侧聊记录跟父会话绑定，重启 DSH 后仍在；只有点「结束此侧边聊天」才会归档消失。

## 安装

```sh
dsh plugin --profile <你的 profile> add dsh-side-chat-pro
```

装完重启 DSH（客户端 bundle 在启动时合成）。

## 使用

1. 在对话正文里选中一段文字。
2. 浮出菜单后点：
   - **侧边栏提问**：文字进入侧聊输入框，确认后发送；
   - **翻译**：弹出小浮层，列出候选译法；
   - **名词解释**：弹出小浮层，给出解释。
3. 点窗口右侧的悬浮球可以随时打开/收起侧聊面板。

## 与上游的差异

| 项 | 上游 0.5.2 | 本版 |
|---|---|---|
| 划词菜单 | 只有「在侧边聊天中提问」 | 提问 / 翻译 / 名词解释 |
| 翻译 | 无 | 带上下文，1–5 个候选译法 |
| 名词解释 | 无 | 带上下文，1–3 句 |
| 父会话上下文 | 无 | 新侧聊自动带最近 5 轮 + 翻页工具 |
| 侧聊记录 | 重启后列表为空 | 重启后仍在，主动结束才归档 |
| 悬浮球 | 无 | 有，可拖动并记忆位置 |

## 已知限制

- 本版是在上游 0.5.2 的**编译产物**上打的补丁，`src/` 目录一并附上便于阅读，但重新构建请以上游仓库为准。
- 划词只在 DSH 窗口内生效；其他 Windows 应用里的划词暂不支持（上游生态里可用 `dsh-select-assist-plus` 补足）。
- 需要 DSH `>=0.2.1-rc.1`。
